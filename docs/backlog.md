# norma backlog

**这份文件是跨会话的记忆。** 任何人（你、我、将来的 norma）在使用或开发中撞到东西，
就往这里加一行；**下一次会话开工前先读它**。

分三类写，因为它们的处理方式完全不同：

- **一、使用摩擦** —— 真实使用中撞到的，带现场。→ 决定 v2 该做什么
- **二、待清** —— 已知要做的小项，不紧急。→ 顺手做
- **三、想法** —— 还没验证的。→ **先别做**

> **已知天花板**（那些是*刻意*的取舍，不是待办）在
> `docs/superpowers/specs/2026-09-15-norma-agent-kernel-design.md` 的 §14，这里不重复。

## 二、待清（已知要做，排在后面）

这些都是 v1 的审查里记下但**按流程刻意没修**的项。ledger 已随 SDD 工作区删除，
这份清单是它们的落点——**别让它们再丢一次**。

- [ ] **`_list_dir` 的 `iterdir()`/`stat()` 异常未加保护** —— 一个权限不足的子项会毁掉整个列表。
      逐项 try，或至少返回「部分列出」。
- [ ] **审计日志的 `args` 未截断** —— `write_file` 的 content 会让日志涨到 MB 级。加个上限。
- [ ] **`POLICY[tool.risk]` 是裸下标** —— 未来新增 `Risk` 成员会在该工具被用到时抛 `KeyError`。
      加一条不变量测试 `assert set(POLICY) == set(Risk)`（见 spec §14）。
- [ ] **`permission.py` docstring 措辞** —— 把「手机远程确认」列为未来实现，可能被读成
      「裁决可以放到远端」。补一句「远程只传答案，判断仍在本地」。
- [ ] **终结事件断言只看 `events[-1]`** —— 一个发出 N 个终结事件的变异能存活。
      加 `assert len(events) == 1` 或计数 `Failed`。
- [ ] **「`max_steps` 计模型回合而非工具调用」未被测试钉住** —— 补一条「一轮多个工具调用 +
      小 `max_steps`」的用例；否则按工具调用计数的实现也能全绿。
- [ ] **`reply is None` 分支无测试** —— `FakeLLM` 永远产出 `Reply`，加一个空轮次的剧本。
- [ ] **审计断言只数条数、不辨身份** —— 三条不同结局刚好凑够 3。加身份断言更稳。
- [ ] **`test_execute_uses_param_defaults` 单独看是弱测试** —— `_echo` 本就有默认值，
      不传参也通过；与 `test_execute_success` 成对才有效。加注释说明。
- [ ] **`tests/test_llm.py` 的 `_llm_capturing` 不 close 客户端** —— 测试层资源小瑕疵。
- [ ] **`README.md` 的「加一个工具」说「加一行」** —— 实际需要
      `name`/`description`/`params`/`risk`/`fn` 五项，措辞改准。
- [ ] **`_read_file` 截断时没有 `[已截断]` 标记** —— 模型不知道看到的是残片。
- [ ] **`_read_file` 的 `max_bytes ∈ {1,2}` 时中文仍报二进制** —— 切片不足一个字符，
      唯一替代答案是返回 `""`（另一种错）。当前可接受，记录备查。

## 三、想法（还没验证，**先别做**）

- [ ] **加 system prompt** —— 目前完全没有。冒烟时模型用英文回答中文提问，一句
      「始终用中文」可能就够。成本极低，可以先做。
- [ ] **`read_file` 支持区间读取（offset/limit）** —— 读不完一部小说的直接解法。
      但**先验证**「文件系统当记忆」的方案够不够，别提前做。
- [ ] **会话持久化** —— 每个会话从零开始。但「每个任务：读几个文件 → 产出一个文件」
      可能已经够用。**等真实使用数据**。
- [ ] **上下文压缩** —— 同上，先看文件系统方案够不够。
- [ ] **`run_shell` 按平台选 shell** —— Windows → PowerShell，POSIX → `sh`。
      macOS 支持的正确形态（见 spec §17）。等有 Mac 验证条件时再做。
- [ ] **打包（PyInstaller 冻结）** —— 让分享变成「下载一个安装包」。与客户端绑定，排在 v2 后。

## 五、会话收尾时做什么

**把状态写进文件，不要留给下一次对话去记。** 具体地：

- 撞到的摩擦 → 加进上面第一张表
- 决定要做的 → 进「待清」，或直接进 spec
- 决定不做的 → 进 spec §14 的已知取舍表（**带上升级路径**）
- 做完的 → 删掉对应行

> 一份没人读的 backlog 等于没有。所以这里只放**真会做**的事——
> 宁可短，宁可空，也不要攒成一份没人看的清单。
